# Design system source: manifest

This folder holds the written guidance from the Arts-Link Design System, built in Claude Design and handed off on 2026-10-02. The files were copied as they were, so this is a reference snapshot, not the source of truth. Tokens, fonts and theming are defined in `assets/css/main.css` and `tailwind.config.js`. Where this folder disagrees with them, the code wins.

## Included

| File | From (handoff `project/`) | What it is |
| --- | --- | --- |
| `readme.md` | `readme.md` | The design guide: company summary, sources, component inventory, content fundamentals (voice), visual foundations, iconography, logo, gaps |
| `SKILL.md` | `SKILL.md` | The agent-skill wrapper for the design system. It sits here as a document; it is not installed under `.claude/skills/` |
| `project-rules.md` | `CLAUDE.md` | Standing rules: American English, US dollars and US date format, plus where proposal contact info goes. Renamed so Claude Code doesn't load it as a nested `CLAUDE.md` when working in this folder |

## Left out

Everything below was left out because it is generated, a prototype, or a second copy of something the repo already defines. None of it was over 1 MB except where noted.

| Path | Why |
| --- | --- |
| `_ds_bundle.js`, `_ds_manifest.json`, `_adherence.oxlintrc.json` | Generated by Claude Design's compiler |
| `styles.css`, `tokens/*.css` (6 files) | Token CSS. It would be a second copy of the palette in `assets/css/main.css` |
| `assets/fonts/*.woff2` (6 files) | Fraunces and DM Sans. Already self-hosted in `static/fonts/` |
| `assets/logo/`, `assets/images/` | Copied from this repo in the first place |
| `components/**` (16 components: `.jsx`, `.d.ts`, `.prompt.md`, `.card.html`) | React reconstructions of the Hugo partials in `layouts/partials/`. The component list and its reasoning are in `readme.md` |
| `guidelines/*.card.html` (19 files) | Foundation specimen cards (HTML previews) |
| `ui_kits/website/` | Click-through prototype of this site |
| `templates/` (marketing page, case study, client proposal, pitch deck) | Claude Design templates. Prices in them are placeholders |
| `Canvas.dc.html`, `thumbnail.html`, `support.js`, `.thumbnail` | Prototype canvas and preview scaffolding |
| `github.md` | Claude Design's sync record (repo, last sync date, map of which design files came from which repo files) |
